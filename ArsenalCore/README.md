# ARSENAL CORE 3.0 — Minecraft 統合版 軍事サンドボックス アドオン

武器 159 種（銃 149・近接 10）、アタッチメント 70 種、防具 27 種、装備 37 種、4 勢力の敵 27 種とボス 4 体、自然生成の構造物 12 種、キルストリーク、兵科とパーク、雇える分隊、ミッションと全 16 話のキャンペーン、武器レベル・階級・チャレンジ、クレジットと店、5 つのゲームモード、HUD 2.0 を収録した、サバイバルでも PvP でもミニゲームでも遊べる銃アドオンです。3D モデル・テクスチャ・効果音はすべてオリジナル（手続き生成）です。

## 導入

1. `ArsenalCore.mcaddon` を開く（PC はダブルクリック、スマホは共有から Minecraft を選択）
2. ワールドの設定 →「ビヘイビアーパック」で **ARSENAL CORE [ビヘイビア]** を有効化（リソースパックは自動で有効）
3. **実験的機能は不要** です

| 必要環境 | |
|---|---|
| Minecraft 統合版 | **1.26.50 以降**（Windows / スマホ / コンソール / Realms / 外部サーバー） |
| Script API | `@minecraft/server` 2.10.0、`@minecraft/server-ui` 2.2.0（安定版のみ） |

初めてワールドに入ると **野戦マニュアル** と **戦術デバイス** が配られます。野戦マニュアルからミッション・兵科とパーク・分隊・設定・図鑑・操作ガイド・戦績・ゲームモードを開けます。2.x のワールドで遊んでいた人にも、3.0 の初回に戦術デバイスが届きます。

### 1.0.2 からの更新手順

1. 念のためワールドをバックアップ（ワールド設定 →「コピー」）
2. `ArsenalCore.mcaddon`（3.0.0）を開いて読み込む。同じ UUID のパックが 3.0.0 に置き換わります
3. ワールドを開くと、ワールド設定・個人設定・持っている武器が自動で 2.0 形式に移行されます
   - 武器の ID・残弾・射撃モード・アタッチメント・弾種はそのまま。2.0 で使えなくなった組み合わせのアタッチメントだけ外れます
   - 1.0.2 で HUD を消していた人・タイトル表示にしていた人は従来型の HUD のまま。ほかの人は HUD 2.0 になります（野戦マニュアル →「HUD・2.0 の設定」で切り替え）
   - 1.0 系のレイダーは新しい戦術 AI で動き始めます
4. 新しい要素（レギオン・ホロウ・構造物・経済・キルストリーク）は既定で有効です。要らなければ野戦マニュアル →「ワールド設定（2.0）」で切れます
5. **アドオンを外すとき** は、先に `/scriptevent arsenal:normalize` を実行して、光学・迷彩の見た目違いの武器を元の ID に戻してください

## はじめの一歩

1. 鉄と石炭で **鋼鉄インゴット** を作り、**兵器作業台** と **弾薬製造機** を置く
2. 作業台で銃・近接武器・防具・装備を作る。武器メニューでアタッチメントを付けると、スコープやドットサイトが **3D モデルに表示** されます
3. 夜になるとレイダーが、山ではレギオンの機械が、地下ではホロウが出ます。構造物を見つけたら守備隊を倒して宝箱を開けましょう
4. 敵を倒すとクレジット・武器経験値・階級経験値が貯まります。補給係（明るい平原・サバンナ・砂漠・タイガに現れる NPC。港や前哨基地にいることも）で買い物、階級 5 から闇市
5. 仲間と遊ぶなら、OP がアリーナツールでアリーナを作ってゲームモードを始めます

## 3.0 の新要素

- **ミッション**（野戦マニュアル →「ミッション」）：いつでも受けられる **依頼**（掃討・情報回収・拠点防衛・賞金首の 4 種、勢力ごと。報酬は階級で増える）と、**キャンペーン「オペレーション・アーセナル」全 4 章 16 話**（各章の最後はボス戦）。受けると 55〜85 ブロック先に目標地点が決まり、HUD とアクションバーに方向と距離が出ます。敵は近づいたときに初めて現れます
- **兵科とパーク**（野戦マニュアル →「兵科・パーク」）：突撃兵・衛生兵・工兵・偵察兵・重装兵の 5 兵科。それぞれ常時の効果と、**戦術デバイス** で使うアビリティ（突撃・回復フィールド・補給・パルス・防壁）を持つ。パークは階級で解放される 12 種から 3 つ（ティアごとに 1 つ）
- **分隊**（野戦マニュアル →「分隊」）：クレジットで味方の兵士を最大 2 人雇える（ライフルマン・機関銃手・選抜射手・衛生兵）。ついて来て敵勢力と敵対モブを撃ち、プレイヤーは撃たない。「ついて来い」「ここで待て」「解散」
- **第 4 勢力「ブラッククロウ」**：夜の森・タイガ・ジャングルに出る民間軍事会社の精鋭 6 種と、煙幕で背後へ回り込むボス「ディレクター・クロウ」（召喚：ブラッククロウの機密ファイル）。前線基地・通信中継所の 2 つの構造物。ワールド設定（2.0）の最後の項目で切れます
- **新しい銃 10 種**：ジャックドー（8 連リボルバー）・フィンチ・マグパイ（50 発 SMG）・グラックル（消音カービン）・スターリング・ルーク・コラックス（全自動切替 DMR）・キングフィッシャー・ブラックウィング（箱型弾倉の散弾銃）・コルヴィッド

## 主なシステム

- **射撃**：ヒットスキャン＋曳光、狙撃は弾道落下と風、照射式（火炎放射・ビーム）、プラズマ・ニードル・迫撃砲・ロケット・有線誘導。部位判定・距離減衰・貫通・制圧
- **特殊武器**：壁で跳ね返る刃・反射レーザー・扇状レーザー、小さなブラックホール（吸い込んで押しつぶす）・時間減速フィールド・衛星砲、自動でロックするスマートピストル・6 発の追尾ミサイル、瞬間移動・味方を回復するビーム・網・麻酔・銛（壁に縫い付ける）・酸（腐食）・EMP 弾・粘着弾・クラスター弾、連鎖する電撃・凍らせる冷気の照射など
- **アタッチメントと見た目**：光学（アイアン／ドット系／倍率スコープ）は 3D モデルに表示。迷彩 8 種は武器レベルで解放
- **防具**：ヘルメットはヘッドショットを軽減、ボディアーマーはプレート（1 枚でダメージ 10）を差し込める。暗視ゴーグル・ガスマスク・ギリースーツ
- **装備**：医療品（包帯・メディキット・アドレナリン・除細動器）、出血、設置物（砲台・シールド・クレイモア・弾薬／医療ステーション・迫撃砲陣地・偵察ドローン）、ライオットシールド
- **敵**：4 勢力 27 種。遮蔽・回り込み・回復・投擲・偵察・自爆を使い分ける戦術 AI（1 tick 8 体までの予算制）
- **ボス**：ウォーロード（増援・空爆・激昂）、ジャガーノート・マーク II（ミサイル・EMP・踏みつけ・部位破壊）、ホロウ・マザー（踏みつけ・群れ）、ディレクター・クロウ（煙幕で回り込み・閃光弾・空爆）
- **構造物**：野営地・前哨基地・武器庫バンカー・研究所・墜落した輸送機・廃港・変異体の巣・検問所・レーダー基地・汚染された農場・ブラッククロウの前線基地と通信中継所。密度はワールド設定で
- **キルストリーク**：偵察・補給投下・砲台投下・空爆・EMP・ガンシップ・誘導ミサイル・核ミサイル（PvP は連続キル、PvE はポイント）
- **核兵器**：置いて 15 秒で爆発する戦術核と、キルストリークの核ミサイル。閃光・きのこ雲・放射性降下物つき。ワールド設定「核兵器」で禁止できます（ブロックを壊すかは爆発の設定に従います）
- **進行**：武器レベル 1〜40、階級 1〜50、デイリー／ウィークリーチャレンジ、統計（野戦マニュアル →「戦績」）
- **経済**：クレジット、補給係の店（買う・売る）、日替わりの闇市
- **HUD 2.0**：弾数・予備弾・射撃モード・状態・熱・プレート・体力・方位・被弾方向・ヒットマーカー・得点・クレジット・風。大きさと配置（スマホ向けの「高め」）を選べます

### 遊び方

1. OP が **アリーナツール** を使い、「新しいアリーナ」で立っている場所を隅 A にする → 反対の隅で「隅 B」→ 各地点で「スポーン地点に追加」（陣取りは「丘」も）
2. 「試合を始める」でモードとアリーナを選ぶとロビーが開きます。ほかの人は **野戦マニュアル →「ゲームモード」→「参加する」**。装備セットもここで選べます
3. 開始すると持ち物・位置・ゲームモード・体力が保管され、装備セットが配られます。試合中は死なず、数秒後に復活します（ホードはウェーブの終わりに復活）
4. 終了後 5 秒で持ち物と位置が元に戻ります。途中で抜けても、ワールドを閉じても、次に入ったときに戻ります

## 既知の制限

- 光学と迷彩を両方付けると迷彩の見た目になります（スコープの効果は付いています）
- 見た目違いの武器はアイテム ID が違うため、ほかのアドオンや `/clear` などの ID 指定では元の武器と別物として扱われます
- HUD 2.0 はタイトルの文字列でデータを受け渡すため、ARSENAL の品を持っている間や試合中は、ほかのアドオン・地図の `/title` が表示されにくくなります（持っていないときは使いません）
- 構造物の展開は、目印の近く（48 ブロック）にプレイヤーが来たときに行われます。展開の瞬間に少し重くなることがあります
- 乗り物（バギー）の運転と段差の越え方はエンジンの操作に依存します
- 迷彩をかけた武器のアイコンは元の武器と同じです（手に持ったモデルと説明文には迷彩が出ます。2.6.5 の軽量化）
- HUD 2.0 のクレジットは、増減してから 5 秒だけ表示されます
- 1 ワールドで同時に進められる試合は 1 つです
- 核の爆発（とくにブロックを壊す設定のとき）は、その瞬間に重くなることがあります
- 退出の直前（最大 5 秒）に得た経験値は保存されないことがあります

## 開発者向け

`python3 tools/build.py` で全アセットを生成し、ビルド時の検証 27 項目（公式スキーマ・言語・商標 209 語・データの整合性・構造物の NBT・HUD 2.0 の往復・負荷試験ほか）とランタイムテスト（モック環境でゲームループを回す）を通してから `.mcaddon` を作ります。設計の判断は [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md)、実機での確認手順は [docs/REALDEVICE_CHECKLIST.md](docs/REALDEVICE_CHECKLIST.md)、変更履歴は [CHANGELOG.md](CHANGELOG.md)。
