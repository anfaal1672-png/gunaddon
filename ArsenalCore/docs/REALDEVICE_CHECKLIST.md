# ARSENAL CORE 2.0 — 実機確認チェックリスト

ビルド時の検証とモック環境のテストでは確かめられない「見た目・操作感・実機のエンジンの挙動」を、実機で確認するための手順です。問題があったら、その場で `/scriptevent arsenal:report` を実行し、表示された内容とスクリーンショットを添えて報告してください（コンテンツログ：設定 → クリエイティブ → コンテンツログを有効に）。

準備：新しいワールド（クリエイティブ、チートあり）に 2.0.1 を入れる。1.0.2 の確認は、1.0.2 で遊んだワールドのコピーを使う。

## 1. 一人称の位置（全機種）

| # | 手順 | 期待 |
|---|---|---|
| 1-1 | `/scriptevent arsenal:give sentinel` で持ち、腰だめで画面を見る | 銃が画面の右下にあり、腕と銃が離れていない |
| 1-2 | スニークで ADS | アイアンサイト（またはドット）が画面中央に来る |
| 1-3 | 武器メニュー（真上を向いて使用）で 4 倍スコープを付ける | 手に持った銃の上にスコープが **3D で** 載る。ADS で全画面のスコープ表示 |
| 1-4 | `/scriptevent arsenal:calib` → ジャンプを何度か押す | 押すたびに銃の高さ・距離が変わる。アクションバーに現在の値 |
| 1-5 | スニーク 2 回 | 保存のメッセージ。以降その位置で表示される |
| 1-6 | スマホ・タブレット・PC でそれぞれ 1-1〜1-3 | どの画面比でも照準が中央に来る |

## 3. 構造物の生成

| # | 手順 | 期待 |
|---|---|---|
| 3-1 | ワールド設定（2.0）で構造物を「多め」にし、平原・サバンナ・砂漠を探索 | 野営地・前哨基地・バンカーが見つかる（近づくと現れる） |
| 3-2 | 山岳で探索 | レギオン研究所 |
| 3-3 | 海岸 | 廃港 |
| 3-4 | 見つけた構造物の見た目 | ブロックの向き（階段・はしご・チェスト）が正しい。浮いていない、地面に埋もれすぎていない |
| 3-5 | 宝箱を開ける | ティアに応じた中身が入っている |
| 3-6 | 守備隊を全滅 | 「○○を制圧した！」とクレジット |
| 3-7 | `/scriptevent arsenal:site raider_camp` | 12 ブロック先に野営地が出る（地形生成を待たずに確認できる） |
| 3-8 | 構造物を「なし」にして新しい土地へ | 構造物が出ない |

特に確認：地形生成で置かれた目印のブロックが自然に展開されるか（**3-1〜3-3**）。展開されない場合は報告してください（ランダム tick の保険が効くまで 1〜2 分かかることがあります）。
